# 体育馆座席视线与安检动线三维图

基于 Three.js 的体育馆三维可视化系统，支持座席视线分析、安检动线模拟、多场景切换等功能。

## 原始需求

> 请用 Three.js 实现体育馆座席视线与安检动线三维图，场景展示看台、舞台或赛场、座席、入口、安检口、通道、无障碍区、售卖点、卫生间和疏散出口。票务、场馆运营和观众服务要查看不同座位的视线遮挡、入场路径、安检排队、退场流向和特殊人群动线；用户点选座席能看到视角预览，切换演唱会、比赛或亲子活动布置后，可售范围、舞台方向和入口策略随之变化。座位数量多时按分区渲染，视线线段、热区和标签需要可开关，避免画面挤成一片。

## 项目简介

本项目是一个体育馆三维可视化系统，主要功能包括：

- **三维场馆展示**：完整展示体育馆看台、舞台/赛场、座席等建筑结构
- **座席视线分析**：点击任意座席可查看视线质量、距离、遮挡情况
- **视角预览**：实时显示所选座席的第一人称视角
- **安检动线模拟**：展示入场路径、安检排队、退场流向和特殊人群动线
- **多场景切换**：支持演唱会、比赛、亲子活动三种场景布置
- **分区渲染**：按北、南、东、西四个分区独立控制显示
- **图层控制**：可开关座席、标签、视线线段、热区、人流动线等图层

## 启动方式

### 前置要求

- Node.js >= 16.0.0
- npm 或 pnpm

### 启动步骤

#### 1. 安装依赖

```bash
npm install
```

#### 2. 启动开发服务

```bash
npm run dev
```

访问地址：http://localhost:3000

#### 3. 构建生产版本

```bash
npm run build
```

#### 4. 预览生产构建

```bash
npm run preview
```

访问地址：http://localhost:4173

## 功能说明

### 视图模式

- **总览**：全景视角，展示所有设施和动线
- **票务视角**：重点展示座席分布、票价区域、可售范围
- **场馆运营**：重点展示安检口、疏散出口、人流动线
- **观众服务**：重点展示入口、通道、无障碍区、卫生间、售卖点

### 场景切换

- **演唱会**：舞台位于南侧，VIP 区靠近舞台，全区域开放
- **比赛**：赛场位于中央，四面看台均开放
- **亲子活动**：舞台偏南，北区不开放，以家庭票为主

### 图层控制

可独立开关以下图层：
- 座席
- 座席标签
- 视线线段
- 视线热区
- 入口
- 安检口
- 通道
- 无障碍区
- 售卖点
- 卫生间
- 疏散出口
- 人流动线

### 分区渲染

支持按北、南、东、西四个分区独立控制座席显示，避免画面拥挤。

### 座席交互

- **鼠标悬停**：高亮显示座席
- **点击座席**：选中座席，显示详细信息、视线分析和遮挡等级
- **视线锥**：从座席到舞台/赛场/大屏的 60° 视线锥可视化
- **遮挡标记**：在三维场景中标出栏杆、音响塔、摄像机位等遮挡物位置
- **遮挡等级**：A 级（无遮挡）→ B 级（轻微遮挡）→ C 级（部分遮挡）→ D 级（严重遮挡），附带票务折扣系数
- **视角预览**：右下角显示所选座席的第一人称视角

### 安检排队模拟

- **排队模拟**：基于时间步进的排队模型，模拟各入口到达率和闸口处理速度
- **热区可视化**：各入口排队人数用彩色圆环和脉冲动画展示等待压力（绿→黄→橙→红）
- **流线展示**：入口到闸口的流线用曲线表示，颜色深浅反映流量强度
- **闸口控制**：可开关任意闸口，关闭后排队人数自动重分配到最近开放闸口
- **无障碍入口**：可将闸口设为无障碍模式，处理时间相应延长
- **志愿者增减**：添加志愿者可提升闸口处理效率 15%
- **围栏调整**：添加/移除围栏可改变人流走向，影响排队分布
- **高峰模拟**：模拟正弦波形的客流高峰变化

## 注意事项

- 建议使用现代浏览器（Chrome、Firefox、Safari 最新版本）
- 首次加载可能需要几秒时间渲染三维场景
- 座席数量较多时，建议关闭部分分区或图层以提升性能
- 鼠标左键拖拽旋转视角，右键拖拽平移，滚轮缩放
